# Rozporządzenia obowiązujące: tekst aktualny / Regulations in force: current text

Repozytorium zawiera obowiązujące rozporządzenia z Dziennika Ustaw (według API Sejmu ELI) w ich obecnym brzmieniu,
tak jak ustawy (USTAWY.md): rozporządzenie z tekstem jednolitym według najnowszego tekstu jednolitego, z datą wejścia
w życie ostatniej zmiany ujętej w tym tekście, podpisane przez organ ogłaszający tekst jednolity (trailer
`Not-included` wymienia zmiany późniejsze); rozporządzenie niezmieniane w brzmieniu ogłoszonym, z datą wejścia w
życie. Pominięto rozporządzenia zmieniające, jednorazowe i indywidualne, zmienione bez tekstu jednolitego, dostępne
tylko jako PDF oraz z tabelami, wzorami lub załącznikami, których parser jeszcze nie czyta. Lista: `data/rozporzadzenia.csv`.

The repository holds the regulations (rozporządzenia) of the Journal of Laws that the Sejm's ELI API lists as in force,
in their current wording, the same way as the acts (USTAWY.md): a regulation with unified texts as the newest one
gives it, dated the day the newest amendment in it took effect (later amendments listed in a `Not-included`
trailer); a regulation never amended as published, on the day it took effect. Amending, one-off and individual
regulations, regulations amended but never consolidated, texts the API has only as PDF, and texts with tables,
formulas or annexes the parser does not read yet were left out. The list: `data/rozporzadzenia.csv`.
